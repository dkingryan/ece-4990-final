# ECE 4990 Final Project

This repository contains the final project for ECE 4990. The project focuses on training and testing a YOLO-based computer vision model for detecting humans in UAV/drone imagery.

The training workflow is contained in a Jupyter Notebook and uses the Ultralytics YOLO library to train a model, run inference on a sample image, and view validation outputs such as precision, recall, F1, and PR curves.

## Repository Contents

```text
.
├── training.ipynb          # Main notebook for installing Ultralytics, training, inference, and validation
├── human.jpg               # Sample image used for inference testing
├── README.dataset.txt      # Dataset source link and license information
├── README.roboflow.txt     # Roboflow export details, preprocessing, and augmentation notes
└── .gitignore
```

## Dataset

The dataset link can be found in [`README.dataset.txt`](README.dataset.txt).

The dataset was provided through Roboflow Universe. Additional dataset export details, including preprocessing and augmentation information, are included in [`README.roboflow.txt`](README.roboflow.txt).

Dataset summary:

- Dataset name: `uav-human`
- Source: Roboflow Universe
- Number of images: 261
- Annotation format: YOLO26
- Class annotated: Human

## Project Requirements

This project uses Python and the Ultralytics YOLO package.

Recommended environment:

- Python 3.10 or newer
- Jupyter Notebook or Google Colab
- Ultralytics
- Pillow
- Matplotlib

Install the main dependency:

```bash
pip install ultralytics
```

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/dkingryan/ece-4990-final.git
cd ece-4990-final
```

2. Download the dataset.

The dataset link is located in:

```text
README.dataset.txt
```

3. Place the downloaded dataset files in the correct YOLO directory structure and make sure the dataset includes a valid `data.yaml` file.

A typical YOLO dataset structure should look similar to:

```text
dataset/
├── data.yaml
├── train/
│   ├── images/
│   └── labels/
├── valid/
│   ├── images/
│   └── labels/
└── test/
    ├── images/
    └── labels/
```

4. Open the notebook:

```bash
jupyter notebook training.ipynb
```

Or upload the repository files to Google Colab and open `training.ipynb`.

5. Run the notebook cells in order.

The notebook performs the following steps:

- Installs the Ultralytics package
- Loads a YOLO model
- Trains the model using `data.yaml`
- Runs inference on `human.jpg`
- Displays the annotated detection result
- Runs validation
- Displays validation curves such as F1, precision-recall, precision, and recall curves

## Training

The notebook trains a YOLO model using:

```python
model.train(data="data.yaml", epochs=200, imgsz=640)
```

The model file can be changed in the notebook depending on which YOLO model size or version you want to use.

Example:

```python
model = YOLO("yolo26m.pt")
```

## Inference

After training, the notebook runs inference on the included sample image:

```python
results = model("human.jpg")
```

The result is plotted with bounding boxes, labels, and confidence scores.

## Validation

The notebook includes validation code that reports metrics such as:

- mAP50-95
- mAP50
- mAP75
- Per-class mAP values
- Per-image precision, recall, F1, true positives, false positives, and false negatives

Validation plots can also be displayed from the generated Ultralytics run directory.

## Notes

- Make sure `data.yaml` points to the correct dataset paths before training.
- If running in Google Colab, update any file paths that reference `/content/runs/...`.
- The dataset itself is not included directly in this repository. Use the link provided in `README.dataset.txt`.
- For validating on the custom UAV-human dataset, use `data="data.yaml"` in the validation call.
